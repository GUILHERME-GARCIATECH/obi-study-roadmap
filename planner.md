# Planner de Estudos — OBI

Objetivo:
- Preparação para a OBI
- Foco em resolução de problemas
- Aprender Java apenas como ferramenta para competição
- Melhorar lógica, velocidade e reconhecimento de padrões

---

# Como usar

Fluxo recomendado:

```txt
tema → resolver problemas → revisar erros → repetir
```

Cada tópico pode virar:
- uma issue
- um treino
- uma lista de exercícios
- um mini simulado
